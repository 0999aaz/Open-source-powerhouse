# Google Play 上架与内测素材清单（供后续如对外发布时参考）

> **当前交付说明**：当前闭环阶段重新回填 `API_BASE_URL` 所构建的 APK **仅供内部验收，不对外分发**。以下清单用于后续若计划正式上架 Google Play 时准备审核素材。

## 1. 图形素材尺寸规范

| 素材类型 | 尺寸 / 规格要求 | 备注 |
| --- | --- | --- |
| 应用图标（App Icon） | `512 × 512 px`，32 位 PNG（支持透明或圆角由 Play 自动裁切），文件大小 ≤ 1 MB | 已在 Android 工程内置自适应矢量图标作为基础图形 |
| 置顶大图（Feature Graphic） | `1024 × 500 px`，JPEG 或 24 位 PNG（无透明通道），≤ 15 MB | 建议展示“GitHub 极客风”深色界面与趋势折线主题 |
| 手机截图（Phone Screenshots） | 至少 **2 张**（建议 **4–6 张**），16:9 或 9:16，短边 ≥ 320 px、长边 ≤ 3840 px，建议 `1080 × 2400 px` | 建议覆盖：1. 榜单日/周/月筛选；2. 语言下拉筛选；3. 详情页与 README 渲染；4. 深色模式；5. 离线横幅与收藏页 |
| 平板截图（可选） | 7 寸与 10 寸平板各自 1–2 张，短边 ≥ 1080 px | 如仅面向手机可先跳过，或在平板模拟器截取 |

## 2. 商店文案与合规信息

- **应用名称**：`GitHub 热门榜`（≤ 30 字符）
- **简短说明**：`追踪 GitHub 每日/每周/每月热门开源项目，支持 30 种语言筛选与离线阅读。`（≤ 80 字符）
- **完整说明**：突出服务端中转、零 GitHub 凭证安全、深浅色极客主题、离线缓存与本地收藏特性。
- **隐私政策链接**：将 [`PRIVACY_POLICY.md`](PRIVACY_POLICY.md) 托管至公网 HTTPS 页面后填入 Play Console。
- **数据安全声明（Data Safety）**：声明不收集个人身份信息，仅在本地存储收藏与缓存，传输过程全程使用 HTTPS 加密。

## 3. Play Console 内测流程说明

1. **创建应用与签名**：在 Play Console 创建应用，启用 **Play 应用签名（Play App Signing）**，使用专属 Upload Key 签名生成 `.aab`（`./gradlew :app:bundleRelease`）。
2. **内部测试（Internal Testing）**：先上传 `.aab` 至内部测试轨道，添加测试人员 Gmail 列表（秒级生效，无需 Google 审核），验证安装、升级弹窗（426）与线上域名连通性。
3. **封闭测试（Closed Testing）**：如个人开发者账号受新规限制，需招募规定数量测试人员连续体验至少 14 天后方可申请生产发布权限。
4. **内容分级与审核提交**：完成内容分级问卷（全年龄 / 无用户生成内容上传）与目标受众声明，确认合规后提交生产轨道审核。
