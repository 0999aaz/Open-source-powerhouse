# 隐私政策（草稿）

**生效日期**：2026-11-24  
**适用应用**：GitHub 热门榜（Android 客户端，包名 `com.example.ghtrending`）

欢迎使用“GitHub 热门榜”。我们非常重视您的隐私与数据安全，请在使用前仔细阅读本说明。

## 1. 数据传输与中转方式

- 本应用不直接连接 GitHub 官方 API，也不要求您登录 GitHub 账号或提交任何个人访问令牌（Token）。
- 热门仓库榜单、仓库详情及 README 文档均由我方服务端定时采集并缓存后，通过加密 HTTPS 连接向客户端提供。
- 为确保客户端版本兼容性及防止接口滥用，客户端向我方服务器发起请求时会携带客户端版本号（`X-Client-Version`）及常规网络请求元数据（如用于限流防护的出口 IP）。我方服务器仅在内存中短期统计请求频率，不将其用于用户画像或广告追踪。

## 2. 本地收集与存储的数据

- 本应用**不设立账号体系**，不收集您的姓名、手机号、邮箱、通讯录、精确地理位置或设备广告标识符（AAID）。
- 您在应用内产生的“收藏仓库”记录、已浏览的榜单缓存及 README 离线缓存**仅保存在您设备本地的 SQLite / Room 数据库中**，不会上传至我方服务器，卸载应用或清除应用数据即可彻底删除。

## 3. 第三方跳转与 GitHub 数据归属

- 当您在详情页点击“在 GitHub 打开”或点击 README 中的外部链接时，应用将调用系统浏览器 / Chrome Custom Tabs 打开对应网页；离开本应用后的浏览行为受目标网站（如 GitHub）各自隐私政策约束。
- 应用展示的开源仓库名称、描述、星数、分叉数与 README 文档均源自 GitHub 公开页面及公开仓库信息，相关知识产权与开源协议归原仓库作者及 GitHub 所有。

## 4. 政策更新与联系我们

如本应用后续新增功能涉及数据处理规则调整，我们将及时更新本隐私政策并在应用发布渠道同步提示。如有疑问，请通过应用发布页面提供的开发者邮箱与我们联系。
